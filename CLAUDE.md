# CLAUDE.md - Project Instructions for Forge

## Permissions
The assistant MAY commit and push changes to GitHub after verification.

## Commands Allowed
- `git add`
- `git commit`
- `git push`
- `git status`
- `git diff`

## Workflow
1. Run full test suite before committing
2. Verify `git diff --check` passes
3. Commit with descriptive message
4. Push to origin
